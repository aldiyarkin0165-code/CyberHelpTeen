# CyberHelpTeen
Проект “CyberHelp Teen” — это веб-сайт для профилактики кибербуллинга среди подростков. Сайт помогает распознавать интернет-травлю, проходить тест, получать советы по защите и узнавать, куда обращаться за помощью. Проект направлен на повышение информированности школьников о безопасном поведении в интернете.
